# Video Labeling Guideline

Label each video into exactly one category before watching content.
Use title + channel name only.

## Categories

**BRAND** — Clearly about Dove soap, shampoo, deodorant, or beauty products.
Example: "Dove Sensitive Skin Body Wash Review"

**CELEBRITY** — About Dove Cameron (the actor/singer).
Example: "Dove Cameron When In Rome Official Video"

**BIRD** — About the bird species.
Example: "Mourning Dove Call and Cooing Sound"

**OTHER** — Music, chocolate, unrelated use of the word Dove.
Example: "Jay Rox Featuring Dove Dee - Kumbucha"

## Rules
- If title mentions "Cameron" → CELEBRITY
- If title mentions "soap", "shampoo", "deodorant", "beauty", "skin" → BRAND
- If title mentions "bird", "call", "cooing", "ringneck" → BIRD
- When unsure, label OTHER
- Never watch the video to decide — title + channel only
